# Siddhartha Pindi — AI Product Manager Portfolio

A responsive, dark-mode portfolio website built with plain HTML, CSS, and JavaScript. No build step or package manager is required.

## Included
- Premium dark visual design with responsive mobile navigation
- Hero section and abstract AI product illustration
- Career impact metrics with a clear validation note
- Filterable project cards: past work and illustrative concepts
- Interactive case-study dialogs
- Product operating principles, responsible AI principles, experience timeline, and contact CTA
- Accessibility basics: semantic sections, keyboard-friendly controls, reduced-motion support, dialog semantics
- GitHub Pages deployment workflow

## Preview locally
Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a public repository named `siddhartha-ai-product-portfolio` (or your preferred name).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
4. Push to the `main` branch. The included workflow publishes the static site.
5. Your site URL will appear under **Settings → Pages** after the workflow completes.

## Before publishing — checklist
- [ ] Replace the LinkedIn link in `index.html` with your actual profile URL.
- [ ] Replace `ADD_YOUR_EMAIL_HERE` in the `data-email` attribute on the contact button with a professional email address.
- [ ] Validate each metric (4× active-user growth, +300% feature adoption, −40% assessment cycle time, and +10% bid win-rate improvement) against approved evidence. Add timeframe, baseline, scope, and attribution where possible.
- [ ] Confirm which details from current and previous employers are approved for public disclosure.
- [ ] Replace generalized descriptions with approved specifics of your ownership, shipped features, collaborators, and results.
- [ ] Keep all screenshots, architecture, customer names, internal URLs, and data confidential unless you have permission to publish them.
- [ ] Remove any metric you cannot substantiate.
- [ ] Add a downloadable resume only if you want one publicly available.

## Content integrity
The AI product experience page is intentionally generalized and does not claim the illustrated interface is a shipped Keyloop feature. The AI evaluation playbook is clearly labelled as a concept; its visual scores are decorative mock data. Other case studies summarize previously documented experience and should be validated before publication.
